# v3.9.1 — Interface and Accessibility Maintenance

## Highlights

- Aligned Trusted Browsers with the redesigned Dashboard,
  Advanced, Diagnostics, Alerts & Notifications, and Alert History pages.
- Standardized the Trusted Browsers header, page width,
  navigation spacing, and content-panel styling.
- Added the System, Dark, and Light theme selector to Trusted Browsers.
- Improved browser-session card layout and revoke-button sizing
  on narrow screens.
- Improved light-theme heading-label contrast across the dashboard.

## Compatibility

- No backend telemetry or alert-processing changes.
- No database schema changes or data migrations.
- No new environment variables, ports, or Docker volume mappings.
- Existing browser authentication and Trusted Browsers
  session management remain unchanged.
- Existing `/data` history and saved configuration are retained.
- The official Unraid template requires no functional changes.

## Validation

- 28 automated axe-core scans covering seven pages,
  desktop/mobile layouts, and Dark/Light themes reported
  zero automated accessibility violations.
- 14 initial keyboard-focus and narrow-screen checks passed.
- Four desktop/mobile visual geometry comparisons against
  Alert History passed.
- Trusted Browsers Python and JavaScript regressions passed.
- Visual layout approved after review in a live dashboard preview.

Automated results do not establish full WCAG 2.2 AA conformance.
Backend-dependent interactions and assistive-technology behaviour
were not fully evaluated.

## Upgrading

Existing installations can retain their current Docker configuration
and persistent `/data` mapping.

Before updating, preserve the existing container settings and
a verified backup of the SQLite database.

After the stable v3.9.1 image is published, use the normal
Unraid Docker update procedure.

See [Upgrade and Rollback](upgrading.md).
