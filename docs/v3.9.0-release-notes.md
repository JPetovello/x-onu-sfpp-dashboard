# v3.9.0 — Remember This Browser

## Highlights

- Optional browser login while retaining the existing HTTP Basic mode.
- Remember This Browser for 1, 3, 7, 14 or 30 days.
- Trusted Browsers page with active-session expiry and revocation.
- Sign out, server-side session expiration, CSRF checks, and rate limiting.
- Session tokens stored as hashes and Secure/HttpOnly/SameSite=Lax cookies.
- Optional trusted-proxy IP configuration for per-client throttling.

## Compatibility

- Updating the Docker image alone does **not** enable browser mode.
- To enable it, supply the existing dashboard credentials,
  `DASHBOARD_AUTH_MODE=browser`, and the exact HTTPS
  `DASHBOARD_PUBLIC_ORIGIN` behind a trusted reverse proxy.
- Existing persistent `/data` and telemetry history are retained.
  The new login system creates its own SQLite session table.
- The GHCR repository and Unraid deployment workflow remain unchanged.
